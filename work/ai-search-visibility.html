Does ChatGPT recommend you?

Buyers ask ChatGPT, Gemini and Perplexity for recommendations before they open Google. If a brand is not in that answer, it is not on the shortlist.

Applied for a B2B IT services firm, a staffing company, and live prospects across home services.

The problem with how it's measured

Most people check this by sending one screenshot of one ChatGPT answer. These models give a different answer each time you ask, so a single check proves nothing. The moment the client tries it and sees something different, the report is done.

What I built

A tool in Python that runs each buyer question 25 times per engine across ChatGPT, Gemini and Perplexity, and reports visibility as a percentage. That number holds up when the client tests it themselves.

25 runs per question 3 engines Percentage + confidence interval Built in Python
What it found
0 of 36
buyer questions where a B2B client was mentioned. Competitors were named instead.

On a live home-services prospect I ran the same test across three cities. The brand showed up in 4 of 9 searches, never in the top three, and in 0 of 3 searches for a service it actually sells.

What I fix
  • Schema and entity clarity so the models can identify the brand
  • llms.txt and AI crawler access
  • Content structured as answers the models can quote

The baseline tells you exactly which questions you are losing and why. Then you fix it and measure the same way to prove it moved.
